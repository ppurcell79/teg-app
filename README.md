# TEG App

Build a mobile first app that works as an interactive wizard based on the attached TEG algorithm for bleeding patients. (it is on page 18. There is further information on page 19) Show one question at a time with buttons that lead to the next logical step.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://teg-app.lovable.app
